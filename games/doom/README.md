# Doom cabinet

Chrome (HTML/CSS/JS + Arcade chip) lives here. The Emscripten `doomgeneric.{js,wasm,data}` bundle is compiled from [njm-cursor-x/web-doom](https://github.com/njm-cursor-x/web-doom) at package time by `scripts/build.sh` and copied into `dist/doom/`. `wad/doom1.wad` is fetched then, never committed.
